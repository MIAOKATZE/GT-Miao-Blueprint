# 文字转蓝图与装饰抵用券

本页对应 v0.1.43 用户测试版本与 GTNH 2.9.0 RC 环境。

蓝图工作区工具栏的“文字蓝图”打开内部悬浮编辑窗，保留当前工作区和视角；可拖动窗口标题调整位置。空白工作区、结构编辑及放置前的蓝图编辑中可用。需要安装 LittleTiles；投影模式、世界定位、施工、未完成采集和只读浏览时不开放。空工作区确认首个文字后成为新的作者蓝图。

顶部“教程”中有独立的“文字附加”预演，演示输入、生成、选位、确认及整体移动。教程使用隔离的教学工作区，结束后返回原状态。

输入多行内容，选择游戏字体、Miao Wiki Pixel、Fusion Pixel、DejaVu Sans 或 DejaVu Serif。游戏字体使用当前资源包的字形；开放字体随 Mod 附带许可证。可调整像素宽高、厚度、加粗、下划线、逐字直立的竖向排列、三个旋转轴、平面弧度、空间弯曲、沿文字扭转和倾斜。平面弧度以文字中点对称展开，竖排以整列竖向中点为基准；空间弯曲与扭转沿同一中心方向计算。平面弧度可设为 360° 形成环形；像素宽高与厚度的单位为 1/16 格。

“颜色与材料”分别设置基础材质与瓷砖染色：新文字默认使用 Chisel 羊毛粘土；羊毛粘土、羊毛、染色陶瓦提供 16 色原生方块图标，已有文字和预设保留原材质；背包以 9×3 与快捷栏的标准槽位选材，也接受方块注册名及元数据。染色可使用 RGB/HSV 调色器、色板或十六进制值，字形和放置预览同步显示材质与染色的叠加效果。切换字体、切页和打开子窗口保留其余草稿设置。RGB `FFFFFF` 保持原材料，其他值使用 LittleTiles 染色瓷砖。材料必须是无容器的普通方块。

空工作区确认内容后直接生成文字；非空工作区先点击可见方块面或空白平面按摄像头选位，顶部「请选择文字位置」炫彩提示。选位期间 R 整体水平旋转、Alt+R 竖转；小键盘 8/2/4/6 或方向键调整平面，Alt + 上下调整高度，也可拖动彩色坐标轴单轴移动，或拖动 XY / XZ / YZ 小面进行双轴平移。蓝图、结构和文字共用同一套位移手柄。虚化预览仅在本地显示。点高亮“确认放置”才向服务器提交，服务器核对蓝图版本、可编辑状态、世界高度、已加载空位和蓝图内容冲突。失败时保留原文字及待放置预览，移动后可重试。

已加入的文字使用紫色轮廓，点击内部同样整体选中；顶部按钮变成“编辑内容”。编辑完成先尝试原位置，冲突则保留待移动状态。蓝图 JSON 保存文本定义，世界中的实体是普通 LittleTiles 瓷砖；从世界重新框选不会凭外观恢复文字定义。

单个文本框最多 512 字符、横向至多 1024×128、竖向高度至多 1024，总面积至多 131,072 像素的栅格、67,108,864 个有效微体素、16,384 个宿主方块；采样另有有限预算。超出时会要求拆成多个文本框或降低尺寸，不会改写原工作区。

管理员使用 `/gtmb voucher` 编辑“猫猫装饰抵用券”的服务器规则。可搜索完整 Mod 名称/ID/版本信息，按 Mod、方块注册名或矿词加入白名单或黑名单。方块写法为 `namespace:block`（所有元数据）或 `namespace:block@meta`；背包样本及 NEI 幽灵拖入不会消耗物品。黑名单优先于所有允许规则。

“保存至服务器”立即生效并保存至 `config/gtmb-decoration-voucher.cfg`；“恢复默认并保存”恢复作者默认规则。多人同时编辑时按配置版本拒绝覆盖新修改，并回显最新规则。保存成功后自动更新已打开的材料核算界面，旧报价与确认失效，重新核算结束后可在原界面继续操作。默认包含羊毛粘土、羊毛、硬化黏土、染色陶瓦及 Et Futurum 混凝土的全部颜色。旧配置首次升级会补齐这些方块；旧配置同时补齐 Ztones 与 Chiseltones 的完整 Mod 默认范围；自定义规则与黑名单保留，之后手动移除的项目不会在重启时反复加回。抵扣只针对实际放置方块和受支持装饰适配器的材料，容器里的物品、设备库存、流体与工业资产继续单独计费。

“升级旧蓝图”按蓝图的 GTMB 版本识别：版本一致或更新时禁用，普通旧版可按需升级但不高亮，早于 v0.1.19 的本地文件处理边界给予高亮提示。升级保留来源整合包及其他 Mod 版本，只更新 GTMB 元数据和兼容存储；缺失来源信息明确保留为未知。JSON/PNG 配对、逻辑 ID 和旧分享别名继续由原事务维护。

工作区有内容时，「清空工作区」以红色高亮。清空工作区会移除当前草稿、选择及本地文字意图，回到空白工作区。实际世界不会因编辑或清空被改变。施工或 AE 下单运行时须先完成或取消任务。

蓝图编辑可选择方块后按 Delete 删除内容，支持撤销和重做；文字保持整体选择，普通结构成员可单格删除。选中控制器结构时，Delete 继续恢复原结构预设外壳，不删除几何。编辑和删除均不会直接改动世界。

文字按实际占用的微体素合并为不重叠的三维长方体，不填平字形孔洞。未额外染色、填满整格且材质有等价普通实心立方体时，直接保存为普通方块；任意染色或特殊渲染材质保留小瓷砖，但完整立方体也只需一个瓷砖条目。定义和文字整体选择身份不受合并影响，材料仍按实际体积核算。

图片附加使用相同的整体选择、选位、旋转、移动和原子冲突流程，详见 [图片附加与像素画](picture-blueprints.md)。

「字体预设」位于「返回工作区」右侧。预设保存字体、像素宽高、厚度、加粗、下划线、竖排、形态参数及颜色与材料；套用时保留当前文本内容和位置，并按新字体重新生成字形。预设列表支持套用、改名和删除。确认文字时，若当前参数不匹配已有字体预设，会弹出「是否保存为预设」，输入名称后选择「保存」或「不保存」继续；关闭弹窗则返回编辑。文字和图片预设分别存于同一个客户端 `config/gtmb-attachment-presets.nbt`，不随蓝图分发。

文字沿用像素宽度与高度，不另外增加统一缩放项。几何生成、精确合并及数据预算检查在后台执行；服务端分批校验，完成后一次加入工作区。处理期间显示进度，可按 Esc 取消，保留原工作区内容。

选用抵用券后优先减免允许的方块费用，即使背包或 ME 已有足量材料，也保留这些库存；设备内部物品等独立费用继续照常支付。

保存蓝图或升级旧蓝图时，按当时服务器规则核对全部有效内容。全部建筑费用均能抵用、且没有内部库存或流体等额外费用时，蓝图写入「完全抵用」标记，在游戏蓝图库右上角显示金色斜跨条幅。蓝图站读取 JSON 内同一布尔标记，在列表预览与详情页显示角标；普通导入、浏览及手工填写同名网站标签不会生成标记。标记描述保存或升级时的结果，实际施工仍按当前服务器规则核算。
