# 添加图片与像素画

以下材质默认值对应 v0.1.28 开发版本；已发布版本见 [Releases](https://github.com/MIAOKATZE/GT-Miao-Blueprint/releases)。

将图片放入当前客户端游戏目录的 `.minecraft/MiaoBlueprintPicture`。工作区顶部点击“添加图片”，自动列出本地图片并读取首张；点击文件名切换，放入新文件后点击“刷新图片”。支持 PNG、JPEG、BMP 和 GIF 首帧，PNG 的透明区域保留。文件最多 16 MiB、原图最多 1600 万像素；最多列出 256 张图片。

入口与文字附加相同：空白工作区、结构编辑和放置前的蓝图编辑可用，需要安装 LittleTiles；世界定位、施工、未完成采集及只读浏览不可用。图片是一体的附加对象，点击其中一格即可选中整幅图片。

“尺寸与材料”默认勾选“保持纵横比”，使用原图比例将短边设为 64 个像素，长边联动计算，与原图本来的像素数量无关。取消勾选后可分别设置横向和竖向像素；重新勾选按短边值恢复原图比例。输出每边最多 1024、总像素最多 1,048,576。每像素默认边长 1/16 格、厚度 1/16 格，像素边长可设为 1–16，超过 16 时须为 16 的倍数，最大 1024；图片厚度可设为 1–64（16 = 1 格，64 = 4 格）；生成体积与编辑距离仍受工作区限制。

新图片默认采用「羊毛粘土为主 + 陶瓦 + 羊毛」：优先匹配 Chisel 的 16 色羊毛粘土，色差明显时用染色陶瓦和羊毛补充。还可选择原有的羊毛与染色黏土、仅羊毛、仅混凝土组合。已有图片和预设保持原有配色。混凝土需要 Et Futurum Requiem。颜色匹配选择这些材料的 16 色变种，不提供自定义材质或任意瓷砖染色。可启用颜色抖动，改善有限色板下的渐变；预览显示转换后的材料色。

“滤镜与抠图”提供原图、黑白、怀旧、反色、色阶、柔化、锐化和轮廓，另可调整亮度、对比度及饱和度。勾选“自动抠图”后，先在量化前找出图片边缘最常见的背景色，再去除与边缘相连的同色区域；被前景包围的内部同色区域保留。背景色容差默认 0，可提高到 64；容差增大也可能去掉边缘相近的前景。透明和抠除区域不生成小瓷砖。

确认图片后，空工作区直接生成新蓝图；非空工作区先点击可见面或空白平面选择位置，再点击高亮“确认放置”。R 整体旋转，Alt+R 竖转；方向键、小键盘、轴线及 XY/XZ/YZ 平面手柄沿用文字附加机制。服务端核对位置、空气和内容冲突，失败保留预览供移动重试。图片不提供文字的弧形、弯曲、倾斜或扭曲。

点击已有图片后，顶部入口变为“编辑图片”；可重新调整尺寸、材料和滤镜。蓝图中保存了有界原图采样数据，分享后即使没有本地原文件也可继续编辑；大图在嵌入前归一化采样，细节受采样和目标分辨率限制。生成几何按相同材料合并精确长方体，不跨颜色填平空洞；等价的单材质完整实心格可保存为普通方块。

移动、复制、Delete、撤销及重做均保持图片整体身份。世界中的结果是普通 LittleTiles 或完整方块，从世界重新采集不会恢复图片编辑身份。上述操作修改工作区草稿，实际施工仍要走原有材料核算。

材料核算按各颜色材料的实际体积计费，支持背包内完整羊毛粘土、羊毛、染色陶瓦或混凝土，也可使用对应的成品瓷砖；同一批施工的不足整格体积累计取整。上述材料的实际放置费用均纳入猫猫装饰抵用券默认规则，服务器黑名单优先；容器内部物品不抵扣。材料不足不会生成方块。保存的候选只记录注册名和变种，施工时从保留的原生数据恢复精确瓷砖形状；已有图片和文字蓝图可直接重新载入核算。

图片预设按钮位于「刷新图片」左边。预设保存分辨率、比例锁定、像素大小、厚度、材料组合、滤镜与抠图参数；保持比例时按当前图片重新计算宽高。预设不会替换当前图片文件、源像素或放置位置。打开列表后可套用、改名、删除。确认图片时，若当前参数不匹配已有图片预设，会弹出「是否保存为预设」，填写名称后选择「保存」或「不保存」；两者都会继续生成，关闭弹窗则返回编辑。预设保存在当前客户端 `config/gtmb-attachment-presets.nbt`，文字与图片列表各自独立。

图片源数据采用有界分块上传；几何生成、瓷砖合并和数据预算计算在后台进行，服务端按批核对位置后一次加入工作区。处理期间显示上传或生成进度，可用 Esc 取消；冲突和超限不会部分替换原内容。图片预览使用转换后的材质色纹理，降低大分辨率下的绘制负担。

单个附加对象最多 16,384 个宿主方块、67,108,864 个有效微体素；蓝图仍有整体数据预算和编辑距离限制。1024×1024 是图片分辨率上限；放大、加厚或高复杂度图片仍可能超过体积、宿主数或数据预算，届时会明确提示调整参数。
