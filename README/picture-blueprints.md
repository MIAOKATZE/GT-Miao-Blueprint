# 图片附加与像素画

适用于 v0.1.23 候选源码；正式发布状态以 Releases 为准。

将图片放入当前客户端游戏目录的 `.minecraft/MiaoBlueprintPicture`。工作区顶部点击“图片附加”，自动列出本地图片并读取首张；点击文件名切换，放入新文件后点击“刷新图片”。支持 PNG、JPEG、BMP 和 GIF 首帧，PNG 的透明区域保留。文件最多 16 MiB、原图最多 1600 万像素；最多列出 256 张图片。

入口与文字附加相同：空白工作区、结构编辑和放置前的蓝图编辑可用，需要安装 LittleTiles；世界定位、施工、未完成采集及只读浏览不可用。图片是一体的附加对象，点击其中一格即可选中整幅图片。

“尺寸与材料”默认勾选“保持纵横比”，使用原图比例将短边设为 64 个像素，长边联动计算，与原图本来的像素数量无关。取消勾选后可分别设置横向和竖向像素；重新勾选按短边值恢复原图比例。输出每边最多 512、总像素最多 65536。每像素默认边长 1/16 格、厚度 1/16 格，两者可在 1–16 之间调整；生成体积与编辑距离仍受工作区限制。

材料仅有三种固定组合：羊毛与染色黏土、仅羊毛、仅混凝土。混凝土需要 Et Futurum Requiem。颜色匹配选择这些材料的 16 色变种，不提供自定义材质或任意瓷砖染色。可启用颜色抖动，改善有限色板下的渐变；预览显示转换后的材料色。

“滤镜与抠图”提供原图、黑白、怀旧、反色、色阶、柔化、锐化和轮廓，另可调整亮度、对比度及饱和度。勾选“自动抠图”后，先在量化前找出图片边缘最常见的背景色，再去除与边缘相连的同色区域；被前景包围的内部同色区域保留。背景色容差默认 0，可提高到 64；容差增大也可能去掉边缘相近的前景。透明和抠除区域不生成小瓷砖。

确认图片后，空工作区直接生成新蓝图；非空工作区先点击可见面或空白平面选择位置，再点击高亮“确认放置”。R 整体旋转，Alt+R 竖转；方向键、小键盘、轴线及 XY/XZ/YZ 平面手柄沿用文字附加机制。服务端核对位置、空气和内容冲突，失败保留预览供移动重试。图片不提供文字的弧形、弯曲、倾斜或扭曲。

点击已有图片后，顶部入口变为“编辑图片”；可重新调整尺寸、材料和滤镜。蓝图中保存了有界原图采样数据，分享后即使没有本地原文件也可继续编辑；大图在嵌入前归一化采样，细节受采样和目标分辨率限制。生成几何按相同材料合并精确长方体，不跨颜色填平空洞；等价的单材质完整实心格可保存为普通方块。

移动、复制、Delete、撤销及重做均保持图片整体身份。世界中的结果是普通 LittleTiles 或完整方块，从世界重新采集不会恢复图片编辑身份。上述操作修改工作区草稿，实际施工仍要走原有材料核算。
