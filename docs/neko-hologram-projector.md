# 猫猫蓝图（投影仪操作说明）

用 1 个 StructureLib 官方“多方块结构全息投影仪”无序合成 1 个猫猫投影仪。物品 ID：`gtmb:neko_hologram_projector`，创造栏：猫猫蓝图。本模组可独立于 GTIT 运行。

## 常用操作

| 要做什么 | 操作 |
| --- | --- |
| 打开工作台或控制器结构 | 手持投影仪对空气普通右键打开工作台时恢复最近使用的「结构」或「蓝图」标签；对准真实控制器普通右键显式打开该控制器的「结构」页，并覆盖上次标签记忆。 |
| 看结构 | 在「结构」标签切换「目标 / 现场 / 差分」，拖动旋转、滚轮缩放，W/S 沿水平视角前后移动摄像机、A/D 左右移动，选择全部层或单层。增强轮廓边缘可选中完整结构；点击结构内部只选单格，只有完整结构可整体拖动。 |
| 独立配置结构 | 每个结构保留自己的配置与区域归属；切换结构不会把设置带到另一结构，离线启停也各自生效。 |
| 选择结构格 | Ctrl+A 全选；Ctrl+点击多选；Shift 拖动选择立体区域；按住 T 点击选择当前结构或非结构区域内的同种方块，GT 机器按实际 MetaTile ID 区分。普通点击单格；线圈等已识别等级部件会自动选择当前结构内的同族。G 切换 RGB 轴，只有完整结构或可独立编辑的非结构格才显示轴；拖动时按住 Ctrl 可复制，意图在拖动开始时确定。 |
| 选中空中位置 | 在结构预览里按住 Alt，用视线射线选取空气格。 |
| 框选世界区域 | 手持投影仪 Shift+右键进入区域选择。左键标一角、右键标另一角，顺序不限，重复点击可调整对应角；首个标记角点时 Ctrl 加选、Ctrl+Shift 减选，该对角点锁定此模式，Ctrl+Z 撤销组合编辑。命中方块时选取实际方块，未命中时才沿镜头射线悬空；Alt 强制悬空，Alt+滚轮调距，距离 0 取脚下。切换快捷栏槽位挂起框选，换回同一投影仪继续；顶部显示操作与挂起提示，红色指向标记当前坐标。再次 Shift+右键完成并导入蓝图；Enter 不拦截，Esc 取消。 |
| 编辑导入区域 | 导入后点击预览中对应结构的淡色边框整选单个识别结构，再用「结构编辑 / 施工」控制；也可切回区域模式编辑整片区域。编辑时仍可使用多选、立体框选及 RGB 轴。 |
| 设置等级和子信道 | 打开「等级 / 信道设置」，连续调整等级或填原始正整数；候选按机器声明家族和当前等级更新，当前家族选择保持不变，无效选项会标明。子信道可输入名称和值，再添加、更新或删除。 |
| 补齐或改造结构 | 控制器结构先完成仓室预设，再确认构建。选「补建」或「替换」和施工范围，再由确认页检查改动。生存模式只填空位，不替换现有方块；替换仅适用于完整的原结构位置。 |
| 浏览蓝图库 | 「蓝图」页显示扁平列表，选行不跳回顶部，也不自动放置。库标题上的「放置所选」进入世界预览；编辑、导入、导出、保存与删除有各自入口。未保存改动时切换蓝图须确认丢弃；覆盖勾选列表只选择保存目标，保存时还须二次确认。 |
| 保存或编辑蓝图 | 从「结构」页前往「蓝图」设置，按实际内容完成必要的作者处理，也可主动打开完整六步核对。必要处理确认且服务端校验完成后，开放「保存蓝图」「保存流程预设」与方块 NBT 细化。已有蓝图从蓝图页编辑 NBT／提示词；需要改变结构时按引导进入「结构」页。点选单格会亮起对应 NBT／提示词入口。保存成功才更新列表；本地保存和下载在聊天显示实际路径与名称。 |
| 设提示或排除方块 | 右下「全局提示词」编辑整份蓝图提示；点选单格可编辑该格提示，不满足条件的操作禁用。自动提示选轻度（必须注意的重新绑定、锚定及保留标签风险）、完整（每个去标识方块说明）或不添加，不覆盖手写提示。可排除所选格，也可恢复施工。 |
| 分享蓝图 | 连接独立服务器时，可将本地蓝图上传到服务器公库，也可下载公库蓝图到本地。手动分享时，将客户端 MiaoBlueprints/ 中的 local_&lt;UUID&gt;.json 与同名 .png 一起复制到对方客户端的同名目录，即可在本地蓝图库查看；文件保留原作者。单份上限 8 MiB。服务器公库文件使用 public_&lt;UUID&gt;.json 与同名 .png；公库上传、下载通过界面处理权限和文件格式。 |
| 每次放置蓝图 | 在库标题点「放置所选」后进入世界 ghost；无方块命中时沿镜头视线悬空显示。仅 Alt+滚轮调节 0–64 格，0 取脚下；普通滚轮仍切快捷栏。绿色预览右键锁定为青色，再右键打开材料与放置确认；锁定时 Shift+右键返回移动。Alt+右键直接使用上一张蓝图。足料确认一次，缺料需再次确认且只放有料的格。绿色/青色 ghost 按 Esc 撤销本次放置，保留蓝图与已付款记录并留在世界中；之后普通右键按最近标签重开。 |
| 查看兼容性和缺失方块 | 蓝图「版本信息」按红色缺失、橙色过时、青色超前显示 Mod 版本；选中缺失方块可查看方块 ID、来源 Mod 与蓝图版本。 |
| 标记 AE 蓝图容器 | 在「结构」预览中单选已适配的 AE 宿主，点「AE 容器标记」编辑虚拟标记；保存前查看数据清理告知、阻塞项和施工材料。背包与 NEI 样本只复制标记，不会消耗或从标记槽取出物品。 |
| AE 材料与下单 | 库存和流体仍使用已启用且有适配的 AE 资源来源；「AE 下单接口」是 provider hook，默认禁用，不包含内置下单或 crafting。 |

普通结构施工使用「材料与改动」核对需求与现场变化；蓝图放置采用「选蓝图—预览并锁定—放置预检—确认放置」流程。蓝图放置始终按整份预设计算施工与材料范围，观察或选中蓝图格不会缩小范围。普通结构中选择 N 格会把施工范围设为这些格；在右侧预览清除格选择可恢复整项范围，切换层只改变预览。施工不播放逐格动画；所有入口沿用服务端安全预检。蓝图的内部库存、流体、储能和覆盖板规则见下方说明。

补建和替换各自处理不同位置。补建只填空位，匹配的现有方块保持原样；调整现有仓室朝向也须使用替换。生存模式所选范围有被遮挡位置时，不启动本次补建、不扣材料。创造模式可以覆盖普通占位方块，控制器、未适配设备、权限及 Forge 事件保护仍有效。

保存蓝图后，原生预览验证、同名 JSON／PNG 双文件提交及最终服务器 owner ACK 均成功才更新蓝图库并选中新条目，列表保持当前浏览位置。本地保存或下载成功后，聊天显示实际路径和名称。覆盖模式选择目标不会载入并覆盖当前编辑内容；「保存蓝图」时才二次确认。已有蓝图可从蓝图页编辑 NBT／提示词，并按条件前往结构页修改几何；未保存切换须明确确认丢弃。

替换须绑定真实控制器，开工前确认原结构已完整构建。只替换已识别的原结构方块或合法仓室，不在空位施工；手动添加的位置、结构声明的空气位置不能用于替换别的建筑。虚拟预设用于补建，需改已有结构时打开其真实控制器。执行中再次核对现场，变化后停止，已完成结果保留。

## 选位置与自由替换

「结构」与「蓝图」是并列标签，右侧有独立属性和蓝图列表面板，并按 Minecraft GUI 缩放适配。蓝图库使用扁平列表，当前行和补充信息分区显示，操作各有独立按钮。工作台已打开时按 Esc 或 E 可退出；有弹窗时先关闭弹窗，文字输入框获得焦点时 E 仍正常输入。世界 ghost 处于绿色或青色时按 Esc 会取消本次放置并留在世界中，不重新打开工作台 UI。Esc 不会在工作台内从「蓝图」切换到「结构」子页。普通点击用于检查位置，不会把施工范围悄悄改成单格。再次点击选中格、点击预览空白或右键可取消选中；主界面「取消格选择」同样可用。Delete 和「恢复默认壳」明确把当前格设回结构默认壳体目标，并抑制预设重新填回；已造仓室要点击「应用替换」才实际回收和还原。无默认壳体的固定接口会说明原因，不猜造外壳。明确指定物品或添加位置后，自动转为单格；批量操作主动选择范围。

| 默认快捷键 | 作用 |
| --- | --- |
| Ctrl+X / C / V | 在结构规划中剪切、复制、粘贴目标和朝向；在蓝图编辑中剪切、复制、粘贴所选蓝图格。蓝图剪切只将源格标为排除，不改动世界。 |
| Ctrl+点击 | 将点击格加入或移出多选。 |
| Ctrl+A | 选择全部当前可选格。 |
| Shift+拖动 | 从已有选择角点或当前格拖到第二点，选择两点之间的立体区域；可同时按 Ctrl 保留已有选择。 |
| 按住 T 并点击 | 选择当前结构或非结构区域内的同种方块；GT 机器按实际 MetaTile ID 区分。 |
| G | 显示或隐藏移动轴；完整结构或可独立编辑的非结构格组可拖轴移动，按住 Ctrl 拖动则复制。操作意图在拖动开始时锁定。 |
| Delete | 恢复选中格的默认壳体目标。 |
| R | 按北→东→南→西→上→下轮询选中仓室的合法朝向。 |
| Ctrl+Z / Y | 撤回、重做最多 32 步目标规划；不回滚世界施工。 |
| 1 / 2 / 3 | 补建、替换、拆除模式。 |

WASD 只移动结构与蓝图预览的摄像机，不改变蓝图格或世界坐标；复位视角同时清除摄像机平移。文字输入框聚焦时 WASD 正常输入；弹窗、改绑、框选、移动轴拖动及 Ctrl／Alt 操作时暂停摄像机移动。普通点击、立体框选和移动轴仍按当前视角定位对应方块。

连续快捷键最多排队 8 项，按服务端确认顺序执行；按世界坐标重新定位，关闭界面、切换会话或采集变化时取消待执行项。

局部剪切、粘贴、恢复外壳和转向保留其它格子的仓室分配；复制不修改规划。剪切只恢复源格壳子，粘贴只改目标格，并保留粘贴前的施工模式和范围。切换选中格、层、范围或施工模式不会重新分配。撤销/重做及蓝图也保留原自动位置；如需按新配额重新安排，请明确重新生成仓室预设。

工具栏「快捷键」展开快捷键表，点击项目后按新的组合键；支持 Ctrl/Shift/Alt，冲突会拒绝，Esc 和无修饰的 1/2/3 保留。设置保存在客户端 `config/gtmb-hologram-keys.properties`，可恢复默认。输入文字、弹窗与改绑捕获时不触发编辑快捷键。

方块选择有「主背包 / 材料来源」两页。来源页能直接选择已启用背包容器和 ME 中的样本，支持点击、拖拽、滚轮翻页和刷新来源。选择物品不会扣材料；清除单格指定后恢复模板目标。来源目录最多展示 96 种可放置样本；只有精确提取接口的背包不能枚举目录，但仍可供应已知目标所需材料。

手动目标允许合法 ItemBlock 或已注册的 GT 机器物品，不再以模板仓室白名单和自动仓室配额限制用户选位；线圈也可手动指定。自动选材仍按原结构规则执行。自由放置**不保证机器成型**，外壳最低数量、仓室种类和结构空气位仍取决于机器本身。

选择物品时，模板空位显示淡线框，可直接点击。没有模板位置时，使用「添加位置」，输入相对控制器的世界 X/Y/Z 偏移；位置须处于世界合法坐标和已加载区块。手动位置未指定目标时不会施工或拆除。重新扫描按坐标保留指定，不按旧列表下标套用。

校准先读取现场合法方块：已审查的材质信道在相关位置一致且唯一匹配时自动识别；线圈格按实际结构声明的线圈家族识别，不依赖仅含当前档位或为空的候选列表，并重新采集目标；这些位置不会被独立覆盖锁死。仓室布局和朝向保留，校准后可继续改变线圈等信道。诸神之锻炉环数读取原机数据；无法可靠反推的尺寸和自定义原始信道保留当前值，结果中明确提示。混合材质不伪造一个统一档位。

## 仓室候选、朝向与预设

选择位置后，右侧显示候选与等级。等级可按可用等级逐级增减；无效选项会标明，不会循环到另一端。候选依据机器声明的类型和家族展开，自动选择遵循同一声明。确认等级后，候选区优先显示该家族与等级的候选项，材料选择列表不会替换当前候选或清除已选家族。Ctrl+A、T、Ctrl+点击与 Shift 框选仍用于选择格子，无需额外的「全选 / 当前 / 同类」按钮。本格候选会标出当前项，支持滚轮浏览，也可在「等级 / 信道设置」打开完整目录；机器自定义校验不能完整解析时会标明已知选项边界。虚拟预设只提供保存的调色板样本。

新放仓室优先面向外部空气，排除模板内部声明空气并遵循仓室与结构定义的合法方向；没有可证明的外部合法空气面时保留原生方向。点击主框「六面转向」或按 R，按北→东→南→西→上→下轮询，自动跳过方块或结构不允许的面。同一现有仓室在替换模式仅修改方向，不拆除、不扣材料；补建模式保留现有方向。新仓室预览材质按目标方向显示。封存设备默认保留自己的方向，显式指定方向只允许方向不同，库存和流体仍须严格一致。

「仓室预设」按选定电压级和冻结的结构声明配额分配目标位置，生成后施工范围同步为全结构，保留已有仓室和手选目标，并共享材料预留数量。关闭降级时严格保持等级；开启后按类型选择不超过目标等级的最高有料级，固定等级部件沿用定义。无仓室设置下，已安装且属于机器必需的合法仓室仍会保留；合法性沿用机器原有校验，手动固定位置优先。材料全缺时保留目标并显示缺口，不把同一枚物品重复算给多个位置。需要取消整机目标时，在预设面板点击「撤销预设」；保留已有仓室与手选目标，已施工结果不会撤回。生成目标后，在「材料与改动」查看需求、已启用来源可用量、主背包数量及控制器自身库存数量；控制器只读展示且受访问权限限制，不参与施工取料。创造模式明确提示普通材料无限，封存设备仍消耗真实物品；TC 罐内容仍须支付真实源质。

预设只适用于能够读取声明配额的定义；未识别的定义和无位置、无等级候选会给出原因。外壳最低数量及其它额外成型检查仍由原机器判断。

## 材料来源设置

「材料来源」入口在工作台内设置主背包、背包容器、ME 三个来源及取料优先级；只启用的来源会参与检索、枚举和取料，设置保存在投影仪中。控制器自身库存数量仍是受权限保护的只读展示，不参与取料。手持投影仪普通右键打开工作台。

- 主背包：跳过手持投影仪的槽位。
- 背包容器：使用 StructureLib 已注册的容器提取器；未知或没有适配器的背包不承诺支持。
- ME：使用玩家携带的第一个无线终端，包括饰品槽。沿用终端原有绑定、范围、电量和提取权限，不需要另绑网络。

每格普通施工失败会退还实际扣除的材料。背包容器保留实际扣料后的状态，材料退到玩家背包；ME 优先退回网络，无法退回的余量进入玩家持久退款暂存。背包满时不会直接丢弃暂存；重新使用投影仪且有空间时继续返还，暂存随玩家持久数据保留。创造模式的普通材料无限，含库存或流体的封存设备仍消耗真实物品，避免复制设备内容。

ArchitectureCraft、CarpentersBlocks、ForgeMultipart、LittleTiles 使用已审阅原生材料描述，可优先使用精确预制成品；原料按实际形状或体积比例，同种精确原料累计后向上取整，不能每格单独进位。Carp 已登记原生坡壳接受精确空 tag 的 damage 0..4，cover／dye 按严格属性路径独立计价；普通壳和属性均按实际原生成本计算一次，真实零成本不要求材料。未审阅独立属性物品仍会阻塞保存，不能用普通壳成本代替属性材料。TC 罐内容须从实际原生源质罐或可用 AE/ThE 源质网络支付；创造模式普通壳免费仍不免内容付款。

## 拆除与设备回收

拆除始终跳过锚点控制器。完整捕获的非空气结构格，包括支持的 GT 仓室、框架和普通方块，均纳入拆除；空气声明且没有显式指定的格子不会拆除，无适配的非 GT 方块实体仍受保护。权限与破坏事件继续生效。

GT 设备的库存、流体及 covers 等保存在回收封存物品中，不迁移到替换后的新仓室。封存物品可恢复原设备；失败路径保留退款与回收物品。具体第三方设备的额外拆除副作用仍由其实现决定。

拆除不再受仓室预设目标影响。默认回收可选「主背包」或「ME 优先」；ME 关闭、终端不可用或网络未全部接收时回落主背包，余量进入玩家持久待领队列。背包满不会因为回收空间阻止安全施工或丢弃物品。回收发生在世界事务成功之后，ME 按实际接收余量计账和收费；施工失败则还原该格、退款实际扣料，不把旧设备掉落重复发放。暂存物在继续使用投影仪、有可用空间时继续投递。任意背包容器只有取料适配，不承诺作为自动回收插入目标。

## 蓝图与流程预设

保存蓝图自动生成同 basename 的 JSON 与无 GUI 原生结构 3D PNG，覆盖时同时替换旧文件；客户端私库与服务端公库的上传、下载、删除，以及手动复制分享，都须处理这对文件。双文件提交失败保留未保存草稿并回滚文件；验证、落盘和匹配的最终服务器 owner ACK 均完成后才更新保存状态。按钮已点击或传输结束不代表保存成功。

JSON 的 `nativeBlueprint` 使用 `formatVersion: 1`；`gtmbVersion` 为 GTMB 独立语义发布版本，当前目标为 `0.1.2`。准确 GTNH 整包版本来自当前环境的 DreamCore `displayedModpackVersion`；不可用时 `gtnhVersion` 为 `unknown`、`gtnhVersionSource` 为 `unavailable`。不读取或迁移旧蓝图文件，旧格式不兼容。

当前编辑蓝图保留信道、目标、朝向、仓室预设和来源选项；保存为蓝图后才能跨会话复用。单人/集成服务器预设在客户端实际游戏目录（通常为 `.minecraft`）的 `MiaoBlueprints/hologram-presets.json`，全库上限 64 MiB、单份 8 MiB；专用服务器与客户端库见下节。处理流程预设继续存放在 `config/gtmb/hologram-processing-presets.nbt`。旧版蓝图目录和集合文件不再读取，也不自动迁移。

作者处理包含六个阶段：**流程预设 → 去标识等级 → 量子网络 → 坐标关系 → 全局 NBT → 自动提示词**。第一步明确选已有流程预设或不使用；可选「倾向自用」或「倾向分享」，服务端按真实内容确定必要阶段，「下一步」可跳过空阶段，仍可返回修改。无 NBT 的普通装饰可直接保存，未知 NBT、身份和坐标关系仍按实际内容审查；也可打开「手动完整六步核对」。私用预选等级0、保留原量子绑定、推荐坐标和轻度提示；当场放置不要求携带量子终端，也不做GTMB安全核验。分享预选等级6、按默认组或自定义组重新选择量子目标、推荐坐标和完整提示，清除源锚定与旧身份；用普通原生已绑定终端选择目标anchor，GTMB不额外做AE安全pair、BUILD检查或native安全验证，不修改GTSWN自身ACL/密钥。显式“清除网络组”可放置未绑定节点后自行连接；原数据的最低身份处理等级仍有效，已清除数据不伪恢复。

量子网络分类是可选设置。不设置时，全部节点自动使用单一「默认网络」，无需打开分类屏或逐图确认，可直接跳过分类或点「下一步」。想拆分和命名网络时，再打开「量子节点网络分类」独立预览：T全选，Ctrl+T选择未选节点，Ctrl+点击切换多选，Ctrl+Z/Y撤销重做。流程预设可预选策略，但不强制本图分类确认。分享放置按实际默认组或自定义组选择背包内普通原生已绑定终端，只读取目标锚点；同一个终端可逐组使用，不附加GTMB安全核验。

坐标关系可逐项选「清除 / 绝对位置 / 相对蓝图」。推荐按实际有效选区判断：内部随蓝图移动，外部自用保留绝对位置、分享清除。relative 只保留相对映射；clear 不保留旧目标。已适配 NC 传感卡真正清除目标须让 card tag 不存在，不能以 (0,0,0) 代替；有额外不透明标签时清除会阻塞，避免丢失数据。

全局 NBT 步骤明确保留/忽略根条目，选择会纳入流程预设。完成后可进一步处理单格 NBT；已审阅配置值必须保持原类型，身份、关系、库存、流体、配方及未审阅数据不提供通用数值修改。相关修改后要重新完成依赖审核。流程预设复用全局策略，不复制设备内容或特定蓝图的单格资产；下次应用仍重新核对实际内容和必要阶段；完整六步核对模式下逐步确认。

服务端确认必要处理完成，或确认普通装饰无需处理后，「保存蓝图」可用；保存流程预设仍按处理界面的确认结果开放。勾选覆盖时，蓝图库只选择要覆盖的目标，保存前二次确认；未保存改动时切换蓝图先确认丢弃。蓝图编辑、提示与保存不会自动启动放置。「旋转查看」只改变查看角度，世界旋转和施工仍按放置流程确认。

世界 ghost 绿色时默认贴合命中方块表面，未命中时悬空；Alt 强制悬空。右键（包括按住 Alt 时）锁定为青色，再右键核对材料与位置；Alt+滚轮调整 0–64 格，普通滚轮切槽。青色锁定后方向键按镜头水平朝向微调一格，Alt+上下调整高度，长按慢速重复。微调会重新核算材料并撤销旧确认；越界或未加载区块时保留原位置。Esc 取消本次放置并留在世界中，保留蓝图与已付款记录。

### 蓝图提示、共享与兼容性

提示词可设在全局蓝图、选中方块或当前区域；提示数据随蓝图保存，图标和悬停说明由数据生成。调整区域提示不会污染单格提示，保存也不会覆盖提示文本。exclude 会把选中格从施工计划排除，恢复操作可重新纳入。蓝图页可导出和导入分享文件，文件由当前服务端单独管理。版本信息列出蓝图依赖的 Mod 版本，并以红、橙、青分别标记缺失、过时、超前；选中缺失方块可查看缺失点、方块 ID、来源 Mod 和蓝图版本。

### 专用服务器蓝图库

连接专用服务器后，蓝图库右上角的小切换可在「客户端」与「服务器」之间切换。客户端蓝图库保存在本机实际游戏目录的 `MiaoBlueprints/`（通常为 `.minecraft/MiaoBlueprints/`），文件为 `local_<UUID>.json` 与同名 `.png`，同一游戏目录下可跨服务器使用并保留原作者；服务器公库位于独立服务端运行目录的 `MiaoBlueprints/`，文件为 `public_<UUID>.json` 与同名 `.png`。集合文件和手动分享文件不会进入本地或公共蓝图列表。客户端上传映射与上次来源设置存放在 `config/gtmb/client-blueprint-library.properties`。服务端 profile UUID 用于上传权属、配额与临时私库 stage，不用于分隔客户端本地文件。上传者可以删除自己上传的公库蓝图，其他玩家可以放置；新蓝图作者信息自动记录，更新时保留原作者，上传者另行记录。

新安装时上传和下载默认各为 128 KiB/s，由全服公平分配；已有配置中的限速保持不变，每位玩家默认最多上传 10 份。OP 4 管理员可在顶部「等级 / 信道设置」左侧打开「管理员设置」，也可用 /gtmblibrary 查看设置，或按 /gtmblibrary set uploadKiB downloadKiB quota 修改。例如，`/gtmblibrary set 128 128 10` 可调整仍保留旧限速的服务器。命令与 config/gtmb/server-blueprint-library.cfg 使用相同配置。

专服中的 Alt 快捷放置会记住最近使用的本地蓝图，并在需要时从客户端私库为当前服务端会话重新暂存。世界 ghost 按 Esc 取消后留在世界中，不会重新打开工作台。打开保存审核等子界面或切换 editor revision 时，当前蓝图名称与作者保持不变；保存后的本地文件使用确认的名称，旧的快捷会话凭据不会覆盖新会话。

全局 NBT 步骤默认保留可写根条目，用户可明确忽略；忽略条目不写入蓝图，设备身份保护字段仍由服务端维护。覆盖板独立选择。放置时可临时取消 NBT 根条目或覆盖板，只影响本次，不修改已保存蓝图。未取消的资源条目按精确数量验料：库存从主背包或通过背包 Wireless Terminal 连接的 AE 网络提供，流体由 AE 网络提供。

EU/RF 储能缓存使用无线 EU。AE 储能缓存优先从背包 Wireless Terminal 连接的 AE 网络支付；没有可用 AE 网络时，需求换算为无线 EU。AE 网络可用但余额不足时不自动切换到 EU，放置为空缓存并提示。背包电池不作为能源来源。原生固有无限能源设备保持原生供能能力。

除上表GTSWN本体免费规则外，普通覆盖板按已安装 side 的实际 cover 物品计价，含 façade 物品 NBT；覆盖板独立关闭时不写回原蓝图选项。带 NBT 的流体若当前 AE2 rv3-beta-1080-GTNH 接口不能保留其 tag，会拒绝保留该条目，不会按无 tag 流体继续；可在保存或本次放置时取消对应根条目。未知 storage 格式同样拒绝，需取消条目或增加适配。

AE 不会替玩家自动下单或制造物品；只使用已启用且适配的材料来源。蓝图遵循已审阅的 AE2 数据格式：来源设备和网络不因蓝图编辑而改变，放置时使用当前施工玩家的新 owner 身份。回滚恢复来源 owner/security，运行中的 AE 网络节点可能重新分配内部编号。未知主机、部件、存储元件或字段会阻止保存；不承诺任意 add-on 数据都能安全清理或还原。

### AE2 蓝图容器与安全保存

在「结构」预览中单选已适配的 AE2 方块或部件，再点「AE 容器标记」。界面展示服务端读取的受支持槽位，并用虚拟图标容器编辑蓝图数据。可从背包或 NEI 选择样本来设置标记；样本不会被消耗。右键、Shift 或 Delete 可清除标记，空白配置样板会被拒绝，界面不提供从标记槽取出物品的操作。

Ghost 配置样本只描述配置，不计施工材料。编码样板、升级卡和空存储元件属于安装材料，保存时只列入材料计划，施工时才由启用的材料来源支付。已审阅的原生 AE cell 和 GTIT Infinity Storage Cell、Infinity Storage Fluid Cell、Neko Infinity Storage Unit 均可适配；蓝图副本会清空其内部物品与流体，保留元件类型、受支持的分区和升级卡，来源世界与元件内容保持不变。未知或未审阅的 storage/cell 格式仍会报告阻塞；无法识别的能源缓存字段则安全清空并告知，不将其计为可支付能源。

蓝图包含 AE 宿主时，完成作者处理并点「保存蓝图」后仍会出现综合报告，列出数据清理告知、警告、阻塞问题和施工材料。查看并确认警告后才能保存；存在阻塞项时不能继续保存。缺少施工材料会提醒但不阻止保存。未审阅的主机、部件或字段会报告阻塞；请按报告清除可处理条目，或替换、删除不受支持的主机。

AE Service 预览按当前「保留」选项临时过滤预览和施工材料计划，不改写源蓝图；施工端按同一过滤结果严格复核材料。蓝图不会继承已审阅宿主的旧网络身份，放置时由当前施工玩家建立新的宿主身份。取消在途导入会保留旧蓝图、磁盘数据和来源库存，不会自动重新打开界面。AE 保存报告在必要作者处理后从真实内容重新核对已适配的主机、部件和资源，必须再次明确确认；空阶段跳过或完整流程模式不会绕过报告、阻塞项或最终服务器 owner ACK。

Drive 与 Interface 的新增原生预览只绘制外观，不读取 NBT、不创建 AE 节点或访问库存；既有六种原生模组的渲染回调保持原实现。当前适配基于 AE2 1080 已审阅的主机、部件和存储元件 schema；未知 add-on 类型或字段会阻止保存，不承诺自动兼容任意 AE 扩展。

## 放置、兼容与施工边界

世界 ghost 只作位置预览；普通右键锁定后，服务端检查权限、锚点、区块和材料。未锁定且没有 GUI 时可按 R 绕世界 Y 轴旋转 90°，按 Ctrl+R 绕世界 X 轴旋转 90°；锚点不变，结果只保留在当前会话，重新完成必要处理并保存蓝图后才持久化。GUI 内 R 仍用于单格转向。若目标姿态无法表达，整份旋转或放置会被拒绝，不会留下部分变换。生存模式不会在受保护或不安全的位置补建；创造模式只可覆盖支持的普通占位，控制器、设备和权限保护仍有效。GT 管道、AE2 和 EnderIO 方向只支持已登记的状态；未知动态模型和私有数据格式不承诺通用呈现。

大型结构可以分批采集，但相关区块需要保持加载。采集未完成或现场变化时不会开始不完整施工；现场变化后操作停止，已完成的格子保留。暂停、继续和取消只控制剩余工作。最终机器成型仍由原机器的结构规则决定；诸神之锻炉的活动状态、环数和已有差异也沿用原机检查。

## 预览与兼容边界

GTSWN v1.8.64 量子节点使用原生 ISBRH 外观，读取审阅的颜色、在线状态、连接方向和 AE 部件外观；链路节点覆盖板读取离线快照，通过原生视觉接口绘制 high 浮雕和两层材质，old／oldplus 沿用 GT 原生覆盖板面。工作台、世界 ghost 和保存 PNG 共用对应预览路径，不运行节点 tick、网络、世界粒子或安装动画。不同质量设置、六向颜色和 AE 部件组合各有独立边界，不承诺所有变体或整包场景均已通过验证。

未知 add-on schema、私有 NBT 和动态模型不作通用兼容承诺；机器最终成型由原模组规则决定。开发验收、历史结果和发布状态见 [计划工作流](https://github.com/MIAOKATZE/GT-Miao-Blueprint-plan/blob/master/workflow/v0.1.0_20261014.md)，维护执行入口见 [构建与验证说明](development-and-validation.md)。
